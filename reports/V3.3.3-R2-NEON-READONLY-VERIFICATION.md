To resolve the Windows process environment isolation constraint without permanently persisting credentials to Windows User/Machine registry scopes or modifying configuration files, a dedicated, self-contained, read-only verification script has been prepared:

- **Methodology:** Executes directly within the user's existing integrated PowerShell terminal process where `$env:DIRECT_URL` and `$env:DATABASE_URL` are already active in memory.

  - Preserves Local Infrastructure: `collabspace-postgres` and `collabspace-redis` remain completely untouched.
